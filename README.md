I design and operate reliable, scalable, and secure cloud platforms. I specialize in Kubernetes, Infrastructure as Code, CI/CD, observability, and platform engineering. My work focuses on reducing operational toil, improving system reliability, and enabling engineering teams to deliver software safely and quickly.

## 🛠️ What I do

- Design and operate enterprise Kubernetes platforms on Azure and AWS.
- Build Internal Developer Platforms (IDP) with Terraform, GitHub Actions, and ArgoCD.
- Implement observability stacks with OpenTelemetry, Prometheus, Grafana, and Alertmanager.
